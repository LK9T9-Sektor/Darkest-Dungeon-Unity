# FEATURE_FLAGS.md — Feature-flag: правило и инфраструктура

## Цель

Всё новое и изменённое user-visible поведение — за feature-flag, чтобы включать/выключать в настройках
**до старта игры и во время игры**, не трогая код. Правило сквозное: применяется к каждой «хотелке».

## Правила

- Новое **выключено по умолчанию**; старое поведение сохраняется (флаг off = как сейчас).
- Семантика переключения: флаги режимов/сессий применяются **со следующего запуска сессии/забега**;
  глобальные настройки UI — сразу.
- Хранение: **глобальные флаги** — PlayerPrefs; **кампания-скоуп** — в настройках кампании (сейв).
- String-идентификаторы флагов; валидация при загрузке (правило AGENTS.md).

## Инфраструктура

- Ядро (`src\Core\Common`, Фаза 0б): модель `FeatureFlag` + `IFeatureFlagSource` (чтение/подписка) и
  `IFeatureFlagStore` (персистентность).
- Unity (презентация): экран настроек до старта (по образцу `SoundSettingsUI`) + окно во время игры.
- Флаг вводится в том же коммите, что и фича.

## Gate

Мини-модель флагов — Фаза 0б; UI настроек — с первым переключателем (презентация или раньше).

## Статус

planned. Cross-cutting: да — касается всех новых фич.
