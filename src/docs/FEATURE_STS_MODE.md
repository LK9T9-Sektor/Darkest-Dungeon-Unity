# FEATURE_STS_MODE.md — Режим «Slay the Spire» (roguelite-кампания)

## Цель

Новый игровой режим в стиле Slay the Spire: нодовая карта, бои и «комнаты»-события с выбором, **без**
передвижения по коридорам и комнатам подземелья (как дорога дилижанса в Darkest Dungeon II). Darkest
Dungeon II уже вдохновлялся больше Slay the Spire — используем этот опыт.

## Состав

- **Нодовая карта** (`src\Core\Modes`): бой / элита / босс / событие / отдых-лагерь / сундук; ветвление
  и выбор игрока.
- **Бой — скиллы DD1** (4 скилла на героя, ранги, стресс): карточный движок не вводим. Нода-награда —
  «выбор 1 из 3 новых скиллов» (аналог STS-карт).
- **События с выбором** — переиспользование систем событий (curios/город) как событийных нод.
- **Отдых** — кэмп; **сундук** — тринкеты/реликвии.
- **Мета-цикл:** roguelite-забег (permadeath) + метарогрессия разблокировок/Ascension между забегами.
- **Сначала соло, затем кооп** (по образцу `FEATURE_COOP.md`).

## Gate

Фаза 1 (Content: события/монстры/боссы), Фаза 3 (Combat), `src\Core\Modes`. Соло-версия — первой.

## Feature-flag

`sts_mode` (off по умолчанию; применяется при создании нового забега).

## Статус

idea. Cross-cutting: частично — новый модуль `Modes`, переиспользует Content/Combat.
