# FEATURE_COOP.md — Кооп-бой PvE

## Цель

Дуэль (1v1: хост → герои, гость → монстры) превращается в кооперативный бой 1–4 игроков в одной
команде против ИИ-монстров/боссов. Сессия до 8 игроков (под будущую арену). Реализует «взаимодействие
в одной команде» первым среди хотелок коопа.

## Состав

- **Владение юнитом per-player:** каждый герой имеет владельца; на ход героя действует только владелец,
  остальные видят отключённую панель (замена веток `IsHost` в `RaidSceneMultiplayerManager`).
- **Отряд:** каждый игрок выбирает 1–4 героев, хост собирает общий отряд из 4; протокол `party_config`
  расширяется на per-player выбор.
- **ИИ:** монстры — ИИ (разрешает хост); ИИ заполняет пустые слоты героев.
- **Победа/поражение** — общие (все монстры мертвы / пал отряд).
- **Authority:** host-authority, идемпотентные команды, общий сид RNG (модель session — см.
  `FEATURE_GAME_MODES.md`).

## Gate

**Фаза 3 (Бой в `src\Core\Combat`)** + её архитектура «симуляция + события для view» (решение принято).
Пока Фаза 3 не выполнена, кооп-бой в Unity-слое не делаем (двойная работа).
