# 00_index.md — планы (архив и отложенные)

Активный план ведётся в `PLAN.md` (корень репозитория). Планы в `docs\plans\` бывают двух видов:

- **отложенный** — `<ГГГГ-ММ-ДД>-<слаг>-deferred.md` (дата — момент отложения): «Состояние»
  (что сделано, что осталось, почему отложено, как возобновить) и ниже исходный план без изменений.
  Возобновлённый план возвращается в `PLAN.md`; файл в архиве удаляется.
- **закрытый** — `<ГГГГ-ММ-ДД>-<слаг>-closed.md` (дата — завершение): «Что сделано» (результат)
  и ниже исходный план без изменений.

Один план — один файл. Мелкие задачи без плана в архив не попадают. Всё в git, чтобы контекст не
терялся при работе с другого ПК; `.opencode\` для планов не используется.

Правила для агентов: `AGENTS.md` (репо) и глобальный `~/.config/opencode/AGENTS.md`
(«Plan persistence»). Навигатор по документации — `docs\INDEX.md`.

## Как отложить план

1. Перенести секцию плана из `PLAN.md` в `docs\plans\<ГГГГ-ММ-ДД>-<слаг>-deferred.md` в том же
   коммите; дата в имени и в шапке — дата отложения.
2. Дописать в начало блок-цитату: `Отложен: <ГГГГ-ММ-ДД>` (ветка, ключевые коммиты) и раздел
   `## Состояние`: что сделано и закоммичено, что осталось, **почему отложено**, что нужно для
   возобновления.
3. Ниже разделителя — исходный план без изменений (в шагах сохраняются текущие `[x]`/`[ ]`).
4. В `PLAN.md` оставить активный (или следующий) план; отложенный упомянуть одной строкой со ссылкой.
5. Добавить строку в таблицу «Отложенные планы»; `CHANGELOG.md` — только если изменение
   user-visible.

## Как закрыть план

1. Дописать в начало файла блок-цитату: `Закрыт: <ГГГГ-ММ-ДД>` (дата завершения), ветка, ключевые
   коммиты.
2. Добавить раздел `## Что сделано` (результат: поведение, файлы, проверки) и, при наличии,
   `## Осталось / за пользователем`; ниже, после разделителя, оставить исходный план без изменений.
3. Перенести секцию плана из `PLAN.md` (или переименовать `-deferred.md` → `-closed.md`) в том же
   коммите, что завершает план; `PLAN.md` оставить с активным (или следующим) планом.
4. Убрать/поправить ссылки на старое имя файла во всех документах (например
   `docs\mechanics\presentation\presentation_wpf.md`).
5. Перенести строку из «Отложенных планов» (если план был отложен) в «Закрытые планы»; дата —
   дата завершения. `CHANGELOG.md` — только если изменение user-visible.
