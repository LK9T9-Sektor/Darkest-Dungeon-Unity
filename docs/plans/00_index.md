# 00_index.md — Планы задач (индекс и архив)

Активный план ведётся в `PLAN.md` (корень репозитория). Завершённый план (все шаги `[x]`)
переносится сюда целиком — цель, решения, шаги, коммиты — и остаётся в git, чтобы контекст не
терялся при работе с другого ПК. Один план — один файл `<slice>.md` (по имени ветки/задачи).
Правила для агентов: `AGENTS.md` (репо) и глобальный `~/.config/opencode/AGENTS.md`
(«Plan persistence»). Навигатор по документации — `docs\INDEX.md`.

## Как пополнить архив

1. Дописать в начало файла плана блок-цитату: статус, ветка, ключевые коммиты.
2. Перенести секцию плана из `PLAN.md` в `docs\plans\<slice>.md` в том же коммите, что завершает
   план; `PLAN.md` оставить с активным (или следующим) планом.
3. Обновить таблицу выше; `CHANGELOG.md` — только если изменение user-visible.
