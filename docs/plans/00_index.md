# 00_index.md — Закрытые планы (архив)

Активный план ведётся в `PLAN.md` (корень репозитория). Закрытый план (все шаги `[x]`) переносится
сюда одним файлом `<ГГГГ-ММ-ДД>-<слаг>-closed.md` — дата в имени и в шапке = дата завершения,
внутри: «Что сделано» (результат) и ниже — исходный план без изменений. Один план — один файл.
Мелкие задачи без плана в архив не попадают. Всё в git, чтобы контекст не терялся при работе
с другого ПК; `.opencode\` для планов не используется.

Правила для агентов: `AGENTS.md` (репо) и глобальный `~/.config/opencode/AGENTS.md`
(«Plan persistence»). Навигатор по документации — `docs\INDEX.md`.

## Как пополнить архив

1. Дописать в начало файла блок-цитату: `Закрыт: <ГГГГ-ММ-ДД>` (дата завершения), ветка, ключевые
   коммиты.
2. Добавить раздел `## Что сделано` (результат: поведение, файлы, проверки) и, при наличии,
   `## Осталось / за пользователем`; ниже, после разделителя, оставить исходный план без изменений.
3. Перенести секцию плана из `PLAN.md` в `docs\plans\<ГГГГ-ММ-ДД>-<слаг>-closed.md` в том же коммите,
   что завершает план; `PLAN.md` оставить с активным (или следующим) планом.
4. Убрать/поправить ссылки на старое имя файла во всех документах (например
   `docs\mechanics\presentation\presentation_wpf.md`).
5. Обновить таблицу выше (строка по дате закрытия); `CHANGELOG.md` — только если изменение
   user-visible.
