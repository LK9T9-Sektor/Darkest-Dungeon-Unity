# Unity 7: боевая сцена фиксирована по высоте + селектор разрешения в настройках

- **Боевая сцена рейда больше не зависит от аспекта по вертикали**: камера (`RaidPartyCamera`)
  пинит высоту кадра мира (141.9156 юнитов = 252.2945×9/16) вместо ширины, поэтому на любом
  аспекте герои/враги сохраняют размер и вертикальную позицию, а по бокам расширяется только
  окружение. На 16:9 картинка не меняется (формула эквивалентна). HUD-канвас `UI_Overlay` переведён на
  match-height, чтобы HP/стресс/лоток/рамка не отрывались от моделей.
- **В окне настроек (шестерёнка) появилась строка «Разрешение»** со стрелками: окно
  переключается по 9 пресетам от 9:16 (портрет) до 32:9 (значение — текущие `ширина x высота`).
  Нужно, чтобы менять разрешение в собранном билде (окно не тянется) для проверки адаптивной
  вёрстки на разных аспектах.
