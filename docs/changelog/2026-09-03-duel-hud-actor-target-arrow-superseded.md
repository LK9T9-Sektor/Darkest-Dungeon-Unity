# Duel HUD: стрелка «актор → цель» по ховеру (заменено выше)

Промежуточная версия стрелки — плоская полоса-«маска» из прямоугольников по центру поля
(предрасчёт 32 масок в `DuelArrowCells`, калибровка колонок по карточкам). **Заменена** на
бейдж + линию со стрелкой (см. «WPF-бой: механики ядра целиком…» выше): `DuelArrowCells`
и `ArrowGrid` удалены.
