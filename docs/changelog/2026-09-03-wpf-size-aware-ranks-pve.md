# WPF: монстры и боссы размером 1–4 ранга + PvE-режим (герои против монстров)

- **Size-aware ранги в ядре** (паритет Unity): ранг юнита назначается кумулятивно по `size`
  (`FormationParty`, `TurnMover`, `SurpriseResolver`, `DuelBattleEvents.MoveUnit`) — size-2 монстр
  занимает ранги 1–2, следующий юнит стартует с ранга 3. Раньше ранги были по индексу (перекрытие
  для больших монстров). Формация — 4 слота (`Σ size ≤ 4`).
- **WPF-вид**: карточка юнита рендерится шириной `185 × size` и занимает N слотов; монстр с size 2–4
  виден «крупным» на своей половине.
- **PvE-режим**: кнопка PvE в главном меню → лобби (4 героя + слоты монстров из каталога, seed,
  Σ size ≤ 4) → бой на чистом ядре `StartFight`: герои игрока ходят, монстры — своими кампанийными
  брейнами, победа/поражение/ничья с баннером.
