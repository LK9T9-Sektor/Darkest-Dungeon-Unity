# WPF: таблица выбора юнитов в VS AI-лобби

- В лобби VS AI добавлена таблица с вкладками `Heroes`/`Monsters`: колонки `Slots` / `Icon` /
  `Class`. У героев показывается иконка, у монстров она пока пустая.
- Выбираются только строки на 1 слот; строки на 2+ слотов серые и не назначаются.
- Клик по слоту выделяет его; двойной клик по строке назначает выбранного героя или монстра
  в этот слот — на стороне игрока или ИИ.
- Стрелки смены класса убраны; ПКМ по слоту героя по-прежнему открывает редактор загрузки.
- Отряды игрока и ИИ могут быть смешанными (герои + монстры); правая сторона ведётся
  кампанийным брейном для монстров и `FallbackDuelAi` для героев.
