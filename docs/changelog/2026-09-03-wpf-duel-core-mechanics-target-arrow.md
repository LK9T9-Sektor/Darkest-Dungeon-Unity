# WPF-бой: механики ядра целиком + стрелка «бейдж скилла → цель»

- **АОЕ и партийные эффекты**: дуэль раскрывает цель через `BattleSolver.SelectSkillTargets` и
  исполняет скилл по каждой цели (как Unity `ExecuteSkillBase`). Hellion `breakthru` бьёт всех врагов
  в рангах, Vestal `gods_comfort` и PD `emboldening_vapours` действуют на всю партию.
- **Валидация целей**: атакующей способностью больше нельзя кликнуть себя или союзника — ядро
  отклоняет невалидную цель в `ExecuteLocalSkill`, выбор скилла сохраняется.
- **Pull/push врага починен**: корень «притяжки/отталкивания не работают» — `ProcessEventQueues`
  итерировал живой список партии, а `MoveUnit` переставлял элементы «коллекция изменена» посреди
  перечисления (падение боя). Теперь итерация по снапшоту `Units`.
- **Баффы/дебаффы на карточках**: `Character.BuffInfos` экспонирован в UI; полоска статусов
  карточки показывает активные баффы/дебаффы (id + остаток раундов).
- **Стрелка цели**: вместо полосы прямоугольников — **бейдж выбранной способности над карточкой
  действующего героя** + прямая линия из его центра в центр наведённой цели со стрелкой на конце
  (чистая математика `Ui/TargetArrowMath`, позиции через `TransformToVisual`). Move-режим — линия
  без бейджа. Оверлей прозрачен для мыши.
- Новые тесты: `DuelSkillExecutionTests` (самоклик/алли-клик отклонены, АОЕ, партийный хил,
  **одиночный хил по кликнутому союзнику**, бафф, pull), `TargetArrowMathTests`, рендер-тест
  стрелки; WPF-тест выбора целей хил-скилла (только союзники, враг игнорируется); lockstep-тесты
  остались зелёными.
