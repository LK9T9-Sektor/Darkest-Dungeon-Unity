# CCG-карточка юнита и каноничные имена героев (WPF-дуэль)

- **Имена героев**: в дуэли имя теперь канонично соответствует классу (Plague Doctor → Paracelsus,
  Highwayman → Dismas, Occultist → Alhazred, Crusader → Reynauld и т.д.) — вместо случайного выбора
  из общего пула по сиду, из-за которого имена «гуляли» между классами и дублировались между
  отрядами. Для классов без каноничного спутника заданы фиксированные нейтральные имена.
  Генерация осталась детерминированной (потребление RNG по сиду сохранено как раньше).
- **Карточка юнита — цельная CCG-карточка** (`DuelUnitCardView`): шапка с именем героя и позицией
  (ранк) в одном ряду; центральная область-«арт» с зарезервированной зоной баффов/дебаффов
  (flow справа налево у левого отряда и слева направо у правого, данные пока не экспонируются);
  подвал с классом героя, HP-полоской со значением и стресс-полоской со значением.
