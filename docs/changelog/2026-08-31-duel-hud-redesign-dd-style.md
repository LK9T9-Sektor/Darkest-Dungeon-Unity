# Duel HUD redesign: DD-стиль боевого экрана (WPF-дуэль)

- **Квест слева**: квест-панель показывает только текст квеста (раунд и имя ходящего убраны),
  прибита к верху-левому углу без пробела сверху, не растягивается на всю ширину; внутри неё
  крестик Retreat.
- **Карточка** — контейнер из двух блоков: сверху вертикальная карточка персонажа (имя по центру
  — не под ранк-бейджем; номер позиции прибит к углу без отступов: герои — правый верх, враги —
  левый; центральная область-«арт» замощена; баффы/дебаффы слева-направо, сверху-вниз; имя класса
  снизу под разделителем — над HP/стрессом), снизу отдельный контрол `UnitStatusBarsView`:
  HP-полоска на всю ширину + значение по центру, стресс-полоска на всю ширину + значение
  (заполненные пипсы с белой обводкой, пустые — серые), у правого края вертикальные полоски
  действий (белая — не ходил, серая — походил; несколько, если способность даёт несколько ходов).
  **Исправлен баг**: полоски действий серы, когда персонаж уже сходил (ядро вынимает юнита из
  `OrderedUnits` при подготовке хода — WPF теперь хранит полный порядок раунда).
- **Поле боя**: карточки прибиты к низу с небольшим отступом (~12), сохраняют естественные
  пропорции (Viewbox с нативным размером — не сплющиваются).
- **Факел и раунд**: верхний ряд — ◀ / глиф пламени / ▶ (глиф затеняется от уровня факела каждые
  25 ед.: 0 — тёмно-серый, выше — желтее/светлее); цифра раунда в кружочке крупным жёлтым текстом;
  под раундом — имя ходящего персонажа цветом его команды (красный — своя, синий — враг).
- **TURN ORDER**: показывается вся последовательность раунда (захватывается в начале раунда), поэтому
  полоса не сворачивается и не прыгает, ходящий не пропадает и держит белую рамку весь свой ход,
  мёртвые тайлы гаснут на месте. Тайл: имя сверху, ниже разделённая рамкой зона под будущую иконку
  персонажа, скорость внизу слева и нароленная инициатива внизу справа (впритык к границам);
  красная/синяя рамка по командам.
- **Полоса способностей** (слева, объединена с панелью статов в один контейнер): квадрат портрета
  ходящего + имя/класс; 4 способности — квадрат только под картинку (имя снизу), доступная — жёлтая
  рамка, недоступная — серая рамка с серым затенением; MOVE — квадрат с ⇄; PASS — **узкий
  вертикальный** прямоугольник с красной рамкой и красным X.
- **DD-панель статов слева** (`HeroInfoPanelView` + `HeroEquipmentView`/`HeroTrinketsView`): только
  статы одним контролом в 2 колонки (HP cur/max, Stress cur/max, ACC, CRIT, DMG мин-макс, DODGE,
  PROT, SPD), контрол снаряжения (глифы мечей/щита + уровни + вытянутые слоты) и контрол тринкетов
  (мешочек по центру + 2 слота); портрет/имя/класс в статах не дублируются.
- **Тултип по наведению** — появляется только при ховере (пустым экранное место не занимает),
  во всю высоту панели, адаптивный (скроллится), с секцией SKILLS.
- **Правая панель**: контент (лог/инвентарь/карта) + вертикальный столбец глиф-кнопок у правого
  края (снизу вверх: INVENTORY, MAP, LOG); карта — единственный квадрат по центру.
