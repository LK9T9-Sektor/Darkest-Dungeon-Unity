# WPF-дуэль: v-образная стрелка перемещения, фикс обрезки бейджа, переиспользуемый контрол скилла

- **Стрелка перемещения (move)** — двуглавая линия ⇄ между **центрами** карточки ходящего и карточки
  цели (обмен рангами с соседним союзником): стрелка у обоих концов, а не одна прямая «верх → центр»
  с единственным наконечником.
- **Бейдж выбранной способности** больше не обрезается сверху: убран лишний подъём `BadgeLift`, позиция
  клампится в границы канваса — бейдж целиком виден над карточкой.
- **Переиспользуемый контрол «квадратик скилла»** (`SkillSquareView`): квадрат с иконкой + имя снизу,
  тултип-подсказка на ховер. Применён в нижнем левом трэе скиллов (вместо инлайнового шаблона) и в
  подсказке персонажа по правой кнопке (вместо голого текста) — скиллы там теперь показываются
  квадратиками с тултипами.
