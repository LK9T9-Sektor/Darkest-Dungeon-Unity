# Тултип способности в WPF-дуэли: читаемое имя + рендер

- **Читаемое имя**: заголовок тултипа (и подписи/бейджа выбранной способности) показывает
  человекочитаемое имя скилла через `Ui.DisplayNames.Title(skill.Id)` («Smite», «Zealous Accusation»),
  а не сырой id.
- **Устойчивый рендер**: корню `SkillTooltipView` задан `MaxWidth=400`, чтобы перенос текста во
  всплывающем `ToolTip` не схлопывался/не обрезался — тултип всегда крупный (бейдж уровня, имя,
  `BaseInfo`, таблица эффектов), как описано в `TESTING.md:242`.
- Новый регресс-тест `SkillTooltip_Open_RendersFully` (`RenderCaptureTests`): реально открывает
  тултип кнопки способности, проверяет DataContext контента, читаемое имя (не id), непустые
  `BaseInfo`/`EffectRows` и ненулевой размер (не «щель»).
