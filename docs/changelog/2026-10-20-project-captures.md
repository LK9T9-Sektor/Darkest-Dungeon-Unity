# Захваты рейда теперь лежат в папке проекта

- Unity-редактор пишет запись рейда в `<repo>\captures\run_<timestamp>\` вместо
  `AppData\LocalLow\...\Replays`; папка добавлена в `.gitignore`.
- WPF при открытии «ВОСПРОИЗВЕСТИ ЗАХВАТ» сам берёт самый свежий `run_*`; ручное копирование
  файлов в `Content\Captures\Reference` больше не нужно.
- Если захватов нет, WPF по-прежнему играет встроенный эталон `1.0.0`.
- Собранная Unity-игра, запущенная вне репозитория, пишет в
  `persistentDataPath\Replays` (прежний fallback).
