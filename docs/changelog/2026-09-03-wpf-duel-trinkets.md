# Тринкеты в WPF-дуэли (P1.4)

- **Тринкеты в дуэли**: у каждого героя 2 слота тринкетов; баффы тринкетов применяются как
  permanent-баффы (`BuffSourceType.Trinket`) и влияют на статы. Парсинг `JsonTrinkets` в `Core.Content`,
  применение — в `DuelController.ApplyTrinkets` (как `ApplyQuirks`), на герое пишутся
  `EquippedTrinketIds`.
- **Выбор в лобби**: у слота героя 2 стрелки-слота тринкетов (цикл + reroll по валидным для класса,
  фильтр `HeroClassRequirements`); выбранные id передаются в отряд через `DuelPartyConfig`.
- **Показ в боевом HUD**: в левой DD-панели контрол тринкетов показывает id баффывающих тринкетов
  (слоты под будущие картинки).
- **Сетевой формат**: `DuelPartyConfig` расширен 5-м `|`-полем `trinkets` (обратная совместимость со
  старыми строками из 4 полей).
- Новые тесты: `DuelTrinketTests` (бафф тринкета меняет стат, id на герое, неизвестный id
  игнорируется), `LobbySlotTests` (слоты/фильтр/reroll), round-trip конфига + legacy-строка.
