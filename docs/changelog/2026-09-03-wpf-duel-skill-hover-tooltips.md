# WPF-дуэль: тултипы скиллов на ховер во всех местах, бейдж иконко-без-текста

- **Тултип скилла снова появляется по ховеру** на квадратиках в подсказке персонажа (ПКМ) и на бейдже
  выбранной способности. Раньше они были не «ховеряемыми» (read-only квадратик отключал хит-тест;
  весь слой стрелок был прозрачен для мыши) — теперь квадратики всегда ховеряются, а рисованные
  линии/стрелки остаются инертными.
- **Бейдж выбранной способности — единый переиспользуемый контрол** (`SkillSquareView`, `ShowName=false`):
  только иконка без текста внутри, имя — в тултипе по ховеру; некликабельный (чистый индикатор).
  Тот же контрол используется в трэе скиллов и в стат-листе — один контрол во всех трёх местах.
