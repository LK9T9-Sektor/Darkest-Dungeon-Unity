# WPF: бейджи скиллов с иконкой, именем и цветом школы

- Над действующей карточкой бейдж показывает иконку и имя выбранной способности — и для игрока,
  и для хода ИИ; у монстров без иконки вместо пустой рамки квадрат цвета школы с инициалами.
- Бейджи `АТАКА`/`ЦЕЛЬ` в карточке красятся по типу способности: атака — красный, баф — синий,
  хил — зелёный; на карточке атакующего пишется имя скилла, на целях — «ЦЕЛЬ».
- Имя скилла выводится под иконкой, бейдж поднят над карточкой и не обрезается; стрелки выходят
  из его края и пересчитываются от фактического размера.
- В воспроизведении захвата бейдж по-прежнему показывает id скилла и красится как атака: тип
  способности в захвате не записывается (отдельный срез).
