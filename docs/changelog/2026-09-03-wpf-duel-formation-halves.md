# WPF-дуэль: формации привязаны к своим половинам (смерти не двигают команды)

- **Боевое поле больше не «схлопывается» при смертях**: команды закреплены за своими половинами с
  фиксированным зазором по центру — герои (ранги 4→1, фронт у центра) справа-выравнивание, враги
  (1→4) слева-выравнивание. Когда юнит умирает, выжившие на его половине сдвигаются к центру
  (рефлоу рангов, как в ядре), но правая команда больше не съезжает влево — центр всегда разделяет
  отряды.
