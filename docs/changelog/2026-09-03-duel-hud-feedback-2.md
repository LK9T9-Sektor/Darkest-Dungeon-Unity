# Duel HUD: фидбек-раунд 2 (карточки, ряд скиллов, ПКМ-статы)

- **Карточка юнита** зафиксирована по аспекту (~0.56, 185×330) — вертикальный портрет больше не сплющивается при ресайзе окна.
- **Нижняя панель** разделена ровно 50/50: слева полоса способностей + статы/инвентарь, справа LOG/MAP/INVENTORY.
- **Способности, MOVE и PASS** — в один горизонтальный ряд без переноса, кнопки выровнены по одной линии (фиксированная высота стеков).
- **Hover-тултип убран**: вся информация по юниту — по ПКМ в непрозрачную панель статов по центру экрана (640×560, тёмный фон, рамка и скругление).
- **Резисты** в панели статов — выровненная сетка 4×2 со значениями в процентах.
- **TURN ORDER**: убраны заголовок и бросок инициативы (внизу тайла осталась только скорость); походившие и мёртвые исчезают из очереди.
- **Факел**: убрано имя/цвет ходящего под кругом раунда.
