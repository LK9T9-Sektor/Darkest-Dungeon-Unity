# WPF: иконки способностей и правило Abomination в лобби

- В слотах лобби VS AI / мультиплеера / PvE способности теперь показаны рядом иконок: выбранные
  подсвечены, при лимите 4 невыбранные серые, тултип структурированный.
- `AbilityRowView` — общий ряд скиллов для SPINE TEST и лобби; `ISkillTileViewModel` — общий
  контракт для боевых и лобби-скиллов.
- Abomination: `can_select_combat_skills false` — все 7 скиллов выбраны и не снимаются, в слоте
  видна пометка `skills locked`. Правило берётся из контента, без хардкода класса.
