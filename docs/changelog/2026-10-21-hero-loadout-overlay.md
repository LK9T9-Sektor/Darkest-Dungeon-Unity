# WPF: компактные слоты и оверлей загрузки героя

- Лобби VS AI / мультиплеера / PvE: слоты героев — четыре компактные иконки с именем и стрелками
  `◀`/`▶` для смены класса.
- ПКМ по слоту открывает full-window `LobbyHeroEditorHost`: широкий оверлей (до 1120×700), гильд-картинка
  фоном от левого верхнего угла, шапка `#позиция / иконка со стрелками / имя / класс / X`, слева
  статы + оружие/броня + тринкеты, справа способности, квирки в две колонки и резисты. Изменения
  сразу уходят в бой; Abomination — все 7 способностей и `skills locked`.
- Выбранные способности — оранжевая рамка, невыбранные — серая рамка + полупрозрачная маска поверх
  иконки (иконка не исчезает); тултип работает и на недоступных/read-only квадратах.
- Хост лежит в корне экрана лобби, поэтому оверлей не ограничен половиной панели VS AI.
