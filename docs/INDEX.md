## Универсальные правила

- **Оба проекта поддерживаются постоянно**: `unity\` (актив.) и `unity-2017\` (легаси). Источник
  истины для домена — `src\Core\`, для сети — `src\Networking\`. Расхождения между деревьями — только
  внутри Unity-кода (UI/движковые особенности).
- **Всё новое — за feature-flag**: выключено по умолчанию, переключается в настройках до старта и во
  время игры (см. `FEATURE_FLAGS.md`).
- **Чистое ядро**: netstandard2.0, C# 7.3, без ссылок на движок/UI (см. «Швы выноса» в `ARCHITECTURE.md`).
- **Документы обновляются в том же коммите**, что и код, меняющий задокументированные факты.
  `CHANGELOG.md` — только для user-visible изменений. Коммиты на английском, с точкой.
