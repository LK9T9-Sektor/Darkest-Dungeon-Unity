# FEATURE_COOP_CAMPAIGN.md — Кооп-кампания (город/имение)

## Цель

Одиночная кампания (уже работает) расширяется под кооп 1–4: взаимодействие игроков с городом/имением,
гибкие настройки общих/раздельных ресурсов, сохранение-загрузка кооп-прогресса.

## Состав

- **Настройки кампании** (per-category флаги): ресурсы/герои/инвентарь — общие или раздельные.
- **Город:** решения по улучшениям/найму — по настройкам кампании.
- **Общий сейв-файл:** единый артефакт кампании; в кооп-сессии синхронизация между игроками (хост
  владеет состоянием, раздаёт актуальный сейв; режоин по session id), плюс оффлайн-продолжение из общего файла.
- **Отряд для походов** — через общий ростер (по настройкам).

## Gate

Фаза 4 (`Campaign` в `src\Core\Campaign`) + Фаза 2 (`Save` в `src\Core\Save`) + кооп-бой
(`FEATURE_COOP.md`) + сессия до 8 (Фаза 5). Порядок: после кооп-PvE-боя.

## Feature-flag

`coop_campaign` (off по умолчанию).

## Статус

idea. Cross-cutting: да — сейв, сеть, кампания, презентация.
